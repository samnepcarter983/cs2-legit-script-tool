## About CS2 Legit Tool

CS2 Legit Tool is designed for Counter-Strike 2 on 64-bit Windows computers. Its feature set combines an ESP overlay, aimbot assistance, bunnyhop automation, and triggerbot functionality within a single utility.

The tool emphasizes a straightforward setup process and settings that can be changed while it is running. Hotkey controls allow features to be enabled or disabled quickly, while live configuration supports fast adjustments during a CS2 session.
